# DJIGIT TAU CRM — инструкция для студии

Адрес: https://djigittau.github.io/djigit-tau-crm/ — открывается на компьютере, телефоне и планшете. На iPhone: Safari → «Поделиться» → «На экран Домой», чтобы CRM открывалась как приложение.

## Вход

- Логин — email или номер телефона, пароль выдаёт директор.
- При первом входе CRM попросит придумать свой пароль.
- Забыли пароль — обратитесь к директору: «Сотрудники» → «Сбросить пароль».

## Первый запуск (директор)

1. **Филиалы** — добавьте филиалы: название, адрес, телефон.
2. **Сотрудники** → «Добавить сотрудника» — имя, телефон или email, роль, филиалы. CRM покажет временный пароль — передайте его сотруднику. Управляющему назначьте его филиалы — других он не увидит.
3. **Настройки** — ставка тренера за занятие (одна для всех).
4. **Группы** — направления танца, группы: филиал, тренер, дни и время, лимит мест.
5. **Расписание** → «Сформировать на 4 недели» — занятия создаются по дням групп. Повторное нажатие не создаёт дублей.
6. **Ученики** и **Родители** — внесите учеников. Родитель с тем же телефоном не задваивается: второй ребёнок привяжется к той же маме.
7. **Интеграция amoCRM** — когда будет готова интеграция в amoCRM (см. README, раздел «Подключение amoCRM»).

Меню разбито на разделы: Клиенты, Занятия, Деньги, Управление. Нажатие на заголовок сворачивает раздел.

## Каждый день

| Кто | Что делает |
|---|---|
| Все | **Смена** → «Начать смену» в начале дня, «Завершить смену» в конце. |
| Отдел продаж | **Заполнение пробников** — новая заявка (телефон, ребёнок, филиал, группа, дата). **Обработка пробников** — двигает заявку по статусам, пишет комментарии, ставит задачи-напоминания. Причина отказа обязательна. |
| Тренер | **Посещаемость** — выбирает своё занятие и отмечает каждого: «Был», «Не был», «Уважительная». Ученика из другой группы можно отметить как отработку. |
| Администратор | **Пробники**, ученики и группы своего филиала; продажа абонемента; аренда, коммунальные, доп. расходы, медстраховка, штрафы. |
| Управляющий | То же по своим филиалам + утверждает зарплаты, смотрит **Аналитику** и **Журнал действий**. |
| Директор | Всё, плюс сотрудники, настройки, amoCRM. |

## Продажа абонемента

Карточка ученика → «Продать абонемент» (или пробник со статусом «Купил абонемент»): название, число занятий, цена, скидка, оплачено, способ оплаты. Ученик, группа, продажа и платёж создаются сразу. Повторное нажатие кнопки вторую продажу не создаёт. Платежи удалить нельзя.

## Зарплата (раз в месяц)

1. **Зарплаты** → «Рассчитать за …». Формула: оклад + занятия по расписанию × ставка + бонусы − штрафы. Отменённые занятия не оплачиваются; сколько учеников пришло — не влияет.
2. Управляющий или директор проверяет и нажимает «Утвердить». После утверждения сумму меняет только директор.
3. «Выплатить» — выплата не может быть больше начисленного.

Тренер видит свои начисления в **Профиле**.

## Отчёты

- **Финансы** — поступления, возвраты, расходы, зарплаты, страховка по месяцам, филиалам и статьям.
- **Аналитика и LTV** — ученики, пробники и конверсия, выручка, расходы, прибыль, средний чек, LTV; фильтры по периоду, филиалу, менеджеру, направлению. При фильтре по направлению или менеджеру расходы и прибыль не считаются: расходы не делятся по направлениям.
- **Журнал действий** — кто, что и когда менял: «было / стало». Изменить или удалить журнал не может никто.

## Безопасность

- Каждый видит только своё: права проверяет база, а не скрытые кнопки. Управляющий не откроет чужой филиал ни по ссылке, ни через API.
- Уволенного сотрудника — **Сотрудники** → «Заблокировать» или «Деактивировать»: вход закрывается сразу.
- Пароли не пересылайте в общих чатах.

## Что нужно сделать студии

1. Supabase → Authentication → Sign In / Providers → Email: включить **Leaked password protection** (запрет утёкших паролей).
2. Для amoCRM: адрес вашей amoCRM и интеграция в amoCRM; ключи `AMO_CLIENT_ID` и `AMO_CLIENT_SECRET` — в Supabase → Edge Functions → Secrets. Подробно — README, «Подключение amoCRM».
3. Неиспользуемую функцию `amocrm-proxy` (от прежней CRM) можно удалить в Supabase → Edge Functions.
