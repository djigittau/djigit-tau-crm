# Город агентов → WhatsApp: где остановились

_Обновлено: 19.11.2026_

## Готово
- В CRM работает раздел «Город агентов»: 7 агентов, включая Карима (amoCRM). Есть автообход каждые 30 минут и уведомления в колокольчике.
- В Supabase (проект `djigit-tau-crm`) развёрнуты функции `amocrm-proxy` и `agents-cron`.
- В Vault создан ключ `agents_key`. Расписание `agents-amo-report` включено: 9:00, 13:00 и 18:00 по Алматы.
- Проверено: функция принимает ключ из Vault и ждёт только данные WhatsApp.

## Остановились на
**Шаг 1. Приложение в Meta.** Нужно зайти на **developers.facebook.com** (не dev.meta.ai), нажать «Мои приложения» → «Создать приложение» и выбрать WhatsApp / Business.

## Дальше по шагам
1. Создать приложение в Meta и добавить продукт WhatsApp.
2. Подключить бесплатный тестовый номер Meta и добавить свой номер-получатель.
3. Создать шаблон `agents_report`: категория Utility, язык Russian, текст «Отчёт агентов DJIGIT TAU: {{1}}».
4. В Supabase → Edge Functions → Secrets добавить `WA_TOKEN`, `WA_PHONE_ID`, `WA_TO`, а для amoCRM ещё `AMO_DOMAIN`, `AMO_TOKEN` и по желанию `AUTO_TASKS=1`.
5. В CRM: «Город агентов» → «Автоматика и WhatsApp» вставить ключ из Vault (`agents_key`) и нажать «Проверить связь».
6. Заменить тестовый токен (живёт 24 ч) на постоянный токен системного пользователя.
7. Позже: попробовать подключить номер студии из WhatsApp Business в режиме совместной работы (Coexistence), чтобы приложение продолжило работать.

Подробности: `supabase/functions/agents-cron/README.md`.
